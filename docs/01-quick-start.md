# 快速开始

## 1. 解压

将发行 ZIP 解压到固定目录，建议路径简短，例如：

```text
D:\KEXU\kexu-portable-win-x64
```

不要在压缩软件预览窗口中直接运行程序。

## 2. 启动

双击：

```text
start-kexu.cmd
```

看到下面的信息后，服务已经启动：

```text
Course studio API listening on http://127.0.0.1:8787
```

浏览器会自动打开系统。若没有打开，访问 `http://127.0.0.1:8787`。

关闭命令行窗口或按 `Ctrl+C` 会停止服务。制作过程中不要关闭这个窗口。

## 3. 检查环境

保持系统运行，双击 `check-env.cmd`，或在命令行执行：

```bat
kexu.cmd doctor
```

正常状态包含：

- Node.js：可用
- Python / edge-tts：可用
- FFmpeg：可用
- Chrome：可用
- API：在线
- 模型：已配置

Chrome 一项也会接受 Microsoft Edge。浏览器缺失时，课件截图和成片渲染无法完成。

## 4. 配置模型

进入左侧“运行设置”，填写：

- 模型服务地址，例如 `https://your-model-service.example/v1`
- 模型名称
- 协议：`chat` 或 `responses`
- API Key

保存后点击“测试连接”。如果模型不可用，系统仍可能用本地结构兜底生成讲稿草稿，但这不是完整的 AI 生产能力。

> 注意：本发行包携带的课程数据中仍保存着制作者本机的模型地址 `http://127.0.0.1:15721/v1`。这个地址只在那台电脑上有效。换电脑后必须改成新电脑可以访问的 OpenAI 兼容服务地址，或者在新电脑上启动同样的模型网关，否则 AI 生成与 Skill 运行会失败。

也可以使用环境配置：

1. 复制 `config\kexu.env.example.cmd` 为 `config\kexu.env.cmd`。
2. 取消需要的行的 `rem`。
3. 重新启动系统。

环境变量的优先级高于界面中保存的设置。一般只需选择其中一种方式。

## 5. 最短制作路径

1. 新建课程，选择“全自动”“口语稿驱动”或“PPT 驱动”。
2. 输入主题、想法草稿、学段、学科、时长与价值引领。
3. 生成讲稿，在讲稿工坊中修改、保存、确认。
4. 生成课件，检查每一页并与讲稿对齐。
5. 选择 AI 旁白或教师试讲。
6. 渲染并下载 MP4，发布课程交付包。
7. 在介质工坊补充概念卡、知识图谱、时间线、问答题等 HTML 介质。

## 6. 教师试讲

在声音与录制模块点击教师试讲，浏览器会请求麦克风权限。全屏界面中上方是课件，下方是讲稿。翻页时会记录页面与时间点，录音结束后保存录制。

使用要求：

- 允许浏览器使用麦克风。
- 使用 Chrome 或 Edge。
- 不要关闭试讲页面。
- 系统会记录翻页事件并按时间轴对齐。

## 7. 数据位置

课程数据位于：

```text
<解压目录>\data
```

主要文件：

```text
data\store.json       课程、讲稿、课件、设置、记忆等结构化数据
data\bootstrap.json   前端启动快照
data\media\           音频、截图、视频、交付包、介质 HTML
data\secrets.json     可选的模型 API Key（首次填写后生成）
```

换电脑前执行 `backup-data.cmd`。它会生成不含密钥的课程数据备份。

## 8. 修改端口

默认端口是 `8787`。如需修改：

```bat
copy config\kexu.env.example.cmd config\kexu.env.cmd
notepad config\kexu.env.cmd
```

将下面一行取消注释并修改：

```bat
set "PORT=8790"
```

重新启动后，访问 `http://127.0.0.1:8790`。CLI 默认仍访问 8787，需要同时设置：

```bat
set "KEXU_BASE_URL=http://127.0.0.1:8790"
```

更简单的做法是只在一个命令行窗口中临时设置 `PORT` 和 `KEXU_BASE_URL`，再启动系统。
