# 课序 KEXU · 使用说明

本说明面向日常使用。安装步骤见《安装说明.md》，专题文档在 `docs` 文件夹。

## 1. 启动与停止

- 启动：双击 `一键启动.cmd`，或桌面“课序 KEXU”快捷方式。浏览器会自动打开 `http://127.0.0.1:8787`。
- 停止：关闭启动窗口、按 Ctrl+C，或双击 `停止服务.cmd`。
- 制作课程、渲染成片的过程中不要关闭启动窗口。

## 2. 界面总览

- 左侧是功能目录，按生产流程分组：工作台、课程项目、讲稿工坊、课件工坊、声音与录制、成片交付；下面是智能体平台（智能体、Skill 库、引擎工坊）、介质工坊、教师记忆。
- 右侧抽屉收纳“智能体动态、运行状态、调度任务”，默认折叠，点右上角图标展开。
- 左下角“运行设置”分五个二级页：模型配置、TTS / ASR、生产环境、视频边框、系统默认。保存按钮统一在页面右下方。

## 3. 三种课程建设模式

新建微课时先选模式，系统会套用对应的工作流（环节可在“引擎工坊”里改）：

| 模式 | 适用场景 | 默认路径 |
| --- | --- | --- |
| 全自动 | 只给主题，希望 AI 推进到底 | 主题 → 讲稿 → 确认 → 课件 → AI 旁白 → 成片 |
| 口语稿驱动 | 教师先自由讲一遍，系统按语音定位页面 | 口述 → 转写/对齐 → 课件 → 合成 |
| PPT 驱动 | 教师围绕课件试讲并录屏录音 | 讲稿 → 课件 → 试讲录制 → 对齐 → 成片 |

## 4. 新建微课

1. 点右上角“新建微课”。
2. 可以直接点录音按钮口述课程设想，说完后智能体会自动分析并填写课程主题、课程名称、学科、学段、时长、价值引领等字段；也可以手写。
3. 确认字段后进入课程生产。

## 5. 讲稿工坊

- 智能体生成结构化讲稿后，右侧是讲稿展示与编辑区，可直接修改并保存。
- 可以对整段提出修改意见并保存；也可以选中某段文字，单独给出意见。
- 讲稿确认后才会进入课件生成，保证后续课件、旁白、字幕都以定稿讲稿为准。

## 6. 课件工坊

- 每个课件生成环节都挂在一个“课件引擎”下，内置结构课件、文字课件、白底 HTML 课件、HTML 课件等多种引擎，可在“引擎工坊”新建引擎并挂载自己的智能体。
- 生成的课件图文并茂：每页可包含图示、步骤、图表、循环、时间线、矩阵等视觉元素，逐页可编辑。
- 系统维护讲稿与 PPT 的对应关系：第一页对应课程主题与导入，第二页对应学习目标，之后按讲稿段落逐页展开，教师试讲时上下能对上。

## 7. 声音与录制（教师试讲）

1. 在“声音与录制”点击“教师试讲”。
2. 进入全屏界面：上方是 PPT，下方是本页讲稿；讲稿以大字号字幕形式整页展示，不需要滚动或翻页。
3. 翻页按钮在 PPT 右侧，尺寸较大，方便对照讲解时点击。
4. 系统同步记录声音与每次翻页的时间点，用于后期对齐与合成。
5. 若在“运行设置 → 生产环境”打开“录制教师画面”，试讲时会同步录制摄像头画面；画面的位置、边框形状与大小可在“运行设置 → 视频边框”里选择方案并保存为默认。
6. 局域网访问时录音录像必须用 HTTPS 地址（端口 8788）。

## 8. 成片与编辑成片

录制或 AI 旁白完成后，声音模块提供两个按钮：

- “进入成片”：直接进入成片流程，合成 MP4 与课程交付包。
- “编辑成片”：进入音轨与文字轨对应的长条编辑界面。横轴是时间，上方是音频轨，下方是逐字稿轨，每一句都能定位到具体时间。

在文字轨上可以挂载自定义介质：

1. 选中某个概念或某句话，选择要挂载的介质类型（概念卡、知识卡、问答卡、清单卡、反例卡、挑战卡、知识图谱等）。
2. 介质以卡片形式出现在时间轴对应位置，样式不同但交互一致。
3. 点“合成 HTML 课程”，系统生成一个全新的 HTML 页面：上端播放课程视频与音频，下端随时间推进弹出挂载的卡片；点击卡片可展开到大窗口查看，展开位置与时间点保持一致。
4. 卡片内容由智能体生成，全部以 HTML 为容器，可自行定制。

这样交付的不只是 MP4，而是一个可交互的 HTML 微课。

## 9. 介质工坊

用于生成视频之外的教学介质：知识图谱、认知地图、概念卡、一图读懂、时间线、问答题等。每种介质都由对应 Skill 生成，产物是独立的 HTML 文件，可以直接打开，也可以挂载到“编辑成片”的时间轴上。

## 10. 智能体平台

- “智能体”：查看与配置系统内的智能体（析课、构页、声场、校尺等）。
- “Skill 库”：查看全部 Skill，可单独试运行某个 Skill 验证效果。
- “引擎工坊”：每个生产环节（析课、讲稿、课件、旁白、成片等）都有一个默认引擎，可以新建引擎，并在引擎下配置调用哪些智能体与 Skill。界面里的“析课”等过程都是可替换的引擎。

## 11. 教师记忆

在“教师记忆”里维护个人长期信息：任教学科、学段、学校、教龄、备课经验、教学心得等。新建微课和生成讲稿时，智能体会结合这些信息调整内容与风格。

## 12. 运行设置

- 模型配置：管理多个模型连接（服务地址、模型名、协议、API Key），支持探测模型列表、测试连接、切换默认连接；推理模型与视觉模型可分别指定。
- TTS / ASR：配置旁白语音与转写引擎（Edge 神经语音、MiMo 等）。
- 生产环境：本机能力检测、录制教师画面开关等。
- 视频边框：选择教师画面的形状、边框与位置，保存方案并设为默认。
- 系统默认：重试次数、本地兜底、品牌标识（可隐藏或自定义右上角文字）等。

## 13. 数据与备份

- 课程数据都在 `data` 目录。
- 双击 `backup-data.cmd` 生成不含 API Key 的数据备份 ZIP，放在 `backups` 目录。
- 换电脑或升级前务必先备份。

## 14. CLI 与 Agent 驱动

先启动系统，再打开一个新的命令行窗口：

```bat
kexu.cmd projects list
kexu.cmd projects create --topic "为什么天空是蓝色的" --grade 初中 --subject 物理
kexu.cmd run project-xxx --json
kexu.cmd render download project-xxx --out .\course.mp4
```

`kexu.cmd schema --json` 会输出全部命令、参数与输入输出契约，Codex 或任何 Agent 都可以按“读 schema → 查项目 → 执行动作 → 检查状态”的方式驱动整套系统。详见 `docs\03-cli.md` 与 `docs\04-agent-integration.md`。

## 15. 常见问题速查

- 页面打不开、端口被占用：见 `docs\07-troubleshooting.md`。
- 模型连接失败：运行设置里重新“测试连接”。
- 录音没有权限：检查浏览器与 Windows 的麦克风权限；局域网用 HTTPS。
- MP4 无法播放：用同目录 FFmpeg 检查文件，或重新渲染。
- 局域网访问与证书：见 `docs\09-lan-access.md`。
