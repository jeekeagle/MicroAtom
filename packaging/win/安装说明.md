# 课序 KEXU · 安装说明

课序（KEXU）是基于智能体的全流程微课制作系统。本发行包是 Windows 便携版：内置 Node.js、Python（edge-tts）与 FFmpeg，解压即可使用，不需要预装开发环境。

## 一、系统要求

- Windows 10 或 Windows 11，64 位。
- 已安装 Google Chrome 或 Microsoft Edge（课件渲染、成片录制与浏览器语音识别依赖它）。
- 磁盘空间约 1 GB（含程序运行时与随包课程数据）。
- 使用 AI 生成、edge-tts 在线合成时需要联网；使用本地模型服务时可离线。

## 二、第一步：解压

1. 把 ZIP 完整解压到一个固定的短路径，推荐：

```text
D:\KEXU\kexu-portable-win-x64
```

2. 不要在压缩软件的预览窗口里直接运行程序。
3. 如果解压后提示“已阻止”“来自其他计算机”，在文件资源管理器中选中解压后的文件夹，右键 → 属性 → 勾选“解除锁定” → 确定。也可以用管理员 PowerShell 执行：

```powershell
Get-ChildItem -Path "D:\KEXU\kexu-portable-win-x64" -Recurse | Unblock-File
```

## 三、第二步：一键安装（每台电脑只需一次）

双击包根目录的：

```text
一键安装.cmd
```

它会自动完成 5 件事：

1. 检查安装包完整性（内置 Node、Python、FFmpeg、服务端、前端与依赖）。
2. 创建课程数据目录 `data`。
3. 生成配置模板 `config\kexu.env.cmd`（保持默认即可，不改端口就不用动它）。
4. 在桌面和开始菜单创建快捷方式“课序 KEXU”。
5. 提示下一步操作。

可选参数（在 PowerShell 中运行时追加）：

- `-EnableLan`：以管理员身份运行时，自动放行 Windows 防火墙的 8787（网页）与 8788（HTTPS 录音）端口，供局域网其他电脑访问。
- `-NoShortcut`：不创建快捷方式。

安装不会修改系统环境变量，也不会向注册表写入服务，卸载只需删除文件夹。

## 四、第三步：一键启动

双击下面任意一个：

```text
一键启动.cmd
桌面的“课序 KEXU”快捷方式
```

首次启动约需 5 到 15 秒，浏览器会自动打开：

```text
http://127.0.0.1:8787
```

没有自动打开时，手动访问这个地址。使用过程中请保持启动窗口打开；关闭窗口、按 Ctrl+C，或双击“停止服务.cmd”，即可停止系统。

## 五、第四步：配置大模型（首次必做）

进入系统左侧“运行设置 → 模型配置”，填写：

- 服务地址：任意 OpenAI 兼容服务，例如 `https://api.example.com/v1`，也可以是本机网关 `http://127.0.0.1:端口/v1`。
- 模型名称：不知道时点“探测模型”，系统会列出服务提供的模型。
- 接口协议：一般选 `chat/completions`。
- API Key：粘贴厂商密钥，点“保存 Key”。
- 最后点“测试连接”，显示“连接正常”即配置成功。

> 注意：随包课程数据里可能保留着制作者本机的模型地址 `http://127.0.0.1:15721/v1`。这个地址只在那台电脑上有效，换电脑后必须改成新电脑能访问的服务，否则 AI 生成会失败（系统仍会用本地结构兜底产出草稿）。

语音部分：默认使用 Edge 神经语音（免费，需联网），可在“运行设置 → TTS / ASR”中切换为 MiMo 等在线引擎。

## 六、可选：局域网访问

默认只监听本机 `127.0.0.1`，最安全。需要让同一局域网内的其他电脑访问时：

1. 用管理员身份运行 PowerShell，执行 `一键安装.cmd -EnableLan`，放行防火墙端口。
2. 用记事本打开 `config\kexu.env.cmd`，取消注释并改为：

```bat
set "HOST=0.0.0.0"
```

3. 重启系统，启动窗口会打印局域网地址，例如 `http://192.168.1.174:8787`，其他电脑用这个地址访问。
4. 局域网内录音、录像必须使用 HTTPS 地址（端口 8788），首次访问需信任本机生成的证书，详见 `docs\09-lan-access.md`。

仅在可信局域网使用。系统当前没有登录认证，不要做端口映射或暴露到公网。

## 七、常见安装问题

**双击后窗口一闪而过**
在文件资源管理器地址栏输入 `cmd` 回车，再运行 `一键安装.cmd`，让错误留在窗口里。多为 ZIP 没有解压完整。

**8787 端口被占用（EADDRINUSE）**
关闭旧的课序窗口；或编辑 `config\kexu.env.cmd` 改 `PORT=8790` 后重启。

**SmartScreen 或杀毒软件提示**
便携脚本未经代码签名。点击“更多信息 → 仍要运行”。脚本只做本机完整性检查、创建快捷方式与启动本地服务。

**浏览器没有自动打开**
手动访问 `http://127.0.0.1:8787`。

**AI 生成失败或超时**
进入“运行设置 → 模型配置”重新测试连接。详见 `docs\07-troubleshooting.md`。

## 八、数据、备份与升级

- 课程数据全部在 `data` 目录：`store.json` 是结构化课程数据，`media` 下是录音、视频、课件与交付包。
- 备份：双击 `backup-data.cmd`，会在 `backups` 目录生成不含 API Key 的数据 ZIP。
- 升级：先备份 `data`，把新版本解压到新目录，再把旧的 `data` 目录复制过去，最后用新目录的一键启动。不要只覆盖程序文件，新旧 `node_modules` 与构建产物可能不兼容。
- 卸载：停止服务后删除整个文件夹，再删除桌面与开始菜单的“课序 KEXU”快捷方式即可。

API Key 只保存在本机 `data\secrets.json`，不随发行包分发，也不会写入备份。不要把该文件发给他人。

详细使用方法见同目录的《使用说明.md》，更多专题文档在 `docs` 文件夹。
