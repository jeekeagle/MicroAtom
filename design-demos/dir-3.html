工作方式

三种工作方式，一套生产线

不同的老师有不同的习惯。课序内置三种默认工作流，也允许按环节重新配置引擎与智能体。

其一全自动

  1. 主题
  2. 讲稿
  3. 课件
  4. 旁白与成片

只给主题，智能体推进到底，教师在关键点确认。

其二口语稿驱动

  1. 口述
  2. 转写与对齐
  3. 课件
  4. 合成

先自由讲一遍，系统按语音定位讲到哪里，再生成课件。

其三PPT 驱动

  1. 讲稿
  2. 课件
  3. 试讲录制
  4. 对齐与成片

对照课件讲，系统记录声音与翻页时间，按试讲时间轴成片。

教师试讲

上方课件，下方大字讲稿

点击试讲，进入全屏。课件在上，讲稿在下以大字号整页展示，不用滚动也不用翻页。翻页按钮放在课件右侧、尺寸够大，对着讲就能点。

  • 字幕式
    整页大字讲稿一眼看清，不用低头找位置
  • 同步记录
    翻页时间与声音一起记供后期精确对齐
  • 可选画面
    录制教师头像系统配置里一个开关，与声音同步录制
  • 对得上
    讲稿与课件逐页对应第一页讲主题，第二页讲学习目标，之后逐段展开
成片编辑台

成片不只是一条视频

声音轨、文字轨、课件轨、介质轨并排铺开。智能体通读逐字稿，定位关键概念，把概念卡、问答卡、知识图谱挂到对应的时间点上。

  • 逐字对齐
    知道哪一秒讲到了哪个概念
  • 挂载卡片
    概念卡、随堂快问、反例、迁移挑战都是 HTML 容器，样式可换、交互一致
  • HTML 课程
    上端播放视频，下端随时间弹出卡片点击卡片展开到大窗口查看
  • 交付
    一节可以点开卡片的课不只是 MP4，而是一个学习环境
智能体平台

每个环节，都可以换

课序把生产拆成五层。上层只依赖下层的契约，不依赖实现——换模型、换引擎、换环节，产品本身不用改。

18个 Skill

最小可复用单元，跨智能体共享，每个都能单独试运行。

4类智能体

析课、构页、声场、校尺各司其职，有记忆、可编排。

∞可配置引擎

新建引擎挂自己的智能体，无需发版即可改变环节行为。

产品层L5
界面、CLI 与交付物。同一份编排，界面上能操作，命令行能操作，外部智能体也能操作。
工作流层L4
环节依赖图与人工确认点。三种默认工作流是三份配置，不是三套写死的代码。
引擎层L3
同一环节的可替换实现：结构课件、文字课件、白底 HTML、交互 HTML 等引擎并存，也可新建。
智能体层L2
析课、构页、声场、校尺——有职责边界、有记忆、可调用 Skill 的角色化编排单元。
能力层L1
概念扫描、问答编写、白底课件、互动课件、卡片合成……18 个 Skill，每个都能单独试运行。

教师记忆

学科、学段、学校、教龄、教学风格与心得存在本地。新建微课时智能体读取它，生成的讲稿与课件自然贴合你的教学习惯。

可被调用

它也能被另一个智能体调用

课序自带 CLI 与 schema 协议。Codex 或任何 Agent 读一遍 schema，就能查项目、跑工作流、取成片——把整条微课生产线当作一个可编排的服务节点。

kexu.cmd schema --json # 读取全部命令与输入输出契约
kexu.cmd projects create --topic "浮力与阿基米德原理"
kexu.cmd run project-xxx --json # 跑完整工作流
kexu.cmd render download project-xxx --out .\course.mp4
部署

装在自己机器上，数据留在本地

一键安装 · 一键启动

Windows 便携版，内置运行环境。解压后双击安装，再双击启动，浏览器自动打开。

通用模型接入

任意 OpenAI 兼容服务都能接入，多档位切换，模型列表可探测。支持 MiMo TTS 与语音识别。

局域网可用

同一办公室的其他电脑也能访问，录音录像走 HTTPS，数据不出这台机器。
